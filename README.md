One sentence, 200 characters at most, pitching a bizarre startup idea that
sounds absurd until you realise it would actually sell.

## The pitch

> We rent out fake paparazzi, strangers with cameras who follow you around the mall for $200 an hour, because everyone treats you like a celebrity once someone else is photographing you.

## Run

```sh
node main.ts
```

It writes the pitch to `/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR` when set).
